# Snip

Find and cancel the subscriptions draining your account.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploy on Vercel

Push to GitHub, then import the repo at [vercel.com/new](https://vercel.com/new). No config needed — Vercel auto-detects Next.js.
